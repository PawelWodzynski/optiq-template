# Zasady Tworzenia Requestów API (React Frontend)

Ten dokument opisuje zasady i dobre praktyki dotyczące wysyłania żądań (requestów) z aplikacji frontendowej React do API backendu.

## 1. Konfiguracja Proxy (Nginx)

Projekt React wykorzystuje konfigurację proxy serwera Nginx (zdefiniowaną w infrastrukturze, np. Docker Compose lub konfiguracji serwera deweloperskiego). Proxy jest skonfigurowane tak, aby przekierowywać żądania wysyłane z frontendu pod określone ścieżki (np. `/login`, `/register`, `/test`) do odpowiedniego serwera backendowego (np. działającego na porcie 8080).

Dzięki temu frontend nie musi znać dokładnego adresu i portu backendu, co ułatwia konfigurację i deployment w różnych środowiskach.

## 2. Konfiguracja Axios (`src/utils/axios.js`)

W projekcie znajduje się plik `src/utils/axios.js`, który zawiera prekonfigurowaną instancję biblioteki Axios. Może on definiować np.:

*   `baseURL` (choć w przypadku użycia proxy często nie jest potrzebne).
*   Domyślne nagłówki.
*   Interceptory do automatycznego dołączania tokenów autoryzacyjnych lub obsługi błędów.

**Zalecane jest zapoznanie się z zawartością pliku `src/utils/axios.js` przed implementacją nowych requestów API.** Używanie tej prekonfigurowanej instancji zapewnia spójność w obsłudze żądań w całej aplikacji.

## 3. Adresowanie Endpointów

Dzięki konfiguracji proxy, żądania do API backendu **muszą** używać **ścieżek względnych**, zaczynających się od `/`.

**Przykłady:**

```javascript
import axios from './utils/axios'; // Import prekonfigurowanej instancji

// Request POST do /login
axios.post('/login', { username, password });

// Request GET do /test
axios.get('/test');
```

**Nigdy nie należy używać pełnych adresów URL backendu w kodzie frontendu**, np. `http://localhost:8080/login`. Zawsze używaj ścieżek względnych, np. `/login`.

## 4. Autoryzacja (Token JWT)

Większość endpointów API wymaga autoryzacji użytkownika. W tym projekcie używany jest mechanizm tokenów JWT (JSON Web Tokens).

*   Token jest uzyskiwany przez użytkownika po pomyślnym zalogowaniu lub rejestracji.
*   Token jest on przechowywany w `localStorage` przeglądarki (const token = localStorage.getItem("token");).
*   **Token JWT musi być dołączany do każdego żądania wysyłanego do chronionego endpointu API.**

Sposób dołączania tokenu może zależeć od konfiguracji backendu i interceptorów Axios. Najczęstsze metody to:

*   **Parametr URL (Query Parameter)**: Jak w poniższym przykładzie, poniewaz backend tego oczekuje.

## 5. Przykład Użycia (Token jako Parametr URL)

Poniższy przykład pokazuje, jak wysłać żądanie GET do endpointu `/test`, dołączając token JWT jako parametr URL o nazwie `token`. Jest to zgodne z przykładowym endpointem backendowym dostarczonym jako wzór (`@GetMapping("/test")` z `@RequestParam String token`).

```javascript
// Przykład requestu GET z tokenem jako parametr URL
import axios from './utils/axios'; // Użyj prekonfigurowanej instancji

const fetchTestData = async () => {
  try {
    const token = localStorage.getItem('token'); // Pobranie tokenu z localStorage
    if (!token) {
      console.error('Brak tokenu autoryzacyjnego');
      // Należy obsłużyć sytuację braku tokenu (np. przekierowanie do logowania)
      return;
    }

    // Dołączenie tokenu jako parametr 'token' w URL
    // Axios automatycznie obsługuje parametry przekazane w obiekcie `params` dla metody GET
    const response = await axios.get('/test', {
      params: {
        token: token
      }
    });

    console.log('Dane testowe:', response.data);
    // Dalsza obsługa pomyślnej odpowiedzi

  } catch (error) {
    console.error('Błąd podczas pobierania danych testowych:', error);
    // Obsługa błędu (np. wyświetlenie komunikatu użytkownikowi)
    if (error.response && error.response.status === 401) {
      // Obsługa błędu autoryzacji (np. token wygasł, przekierowanie do logowania)
    }
  }
};
```

**Uwaga:** Zawsze upewnij się, w jaki sposób dany endpoint backendowy oczekuje przekazania tokenu (nagłówek czy parametr) i dostosuj kod frontendu lub konfigurację Axios (`axios.js`) odpowiednio.
